# Simulating Generic AI Web Content

This example demonstrates the core concern of the article: how an abundance of AI-generated content might make the web less usable. It simulates generic, repetitive AI-like text and contrasts it with a more specific, human-written paragraph to highlight the potential loss of originality and depth.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
